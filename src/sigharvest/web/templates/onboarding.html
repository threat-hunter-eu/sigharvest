Welcome to sigharvest

sigharvest collects public Sigma rules from GitHub, removes duplicates and lets you search and export them. Your index is empty, so let's fill it. It takes about 10 minutes the first time.

  1. Install sigharvest done, you are looking at it
  2. Choose your sources done by sigharvest init; see them on Sources
  3. Download and index the rules clones each repository on your machine; run it again any time to refresh {{ cmd('c-update', 'sigharvest update') }}
  4. Reload this page the overview, search and coverage pages fill in automatically

Want only the SigmaHQ rules? Start a workspace with sigharvest init --preset sigmahq. SIEM queries need the optional backends:
