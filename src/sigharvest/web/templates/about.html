What sigharvest does

sigharvest clones public Sigma rule repositories, finds the same detection logic across them (one entry per logic, however many copies exist), and keeps where every copy came from and under which licence.

It validates every rule with pySigma and the Sigma schema, converts it to SIEM queries when the optional backends are installed, and lets you search, compare and export the result.

Sources (git)→De-duplicate→Validate & convert→Index→Search & export

"Unique rule" = one detection logic. "Copies" = the same logic found in other files or repositories. "Variants" = versions of the same rule (same id or a related: link) whose detection differs.

Data and privacy

  • Everything runs on your machine. The only network calls are the git clones of your sources and, once, the MITRE ATT&CK catalogue.
  • This interface listens on 127.0.0.1, has no accounts and sends nothing anywhere. It loads no fonts, scripts or styles from other sites.
  • Rule text comes from public repositories and is shown as text only; it is never run.
