How to add a source

Any git repository with Sigma rules works. Add it, then update:

sigharvest sources add https://github.com/OWNER/REPO
sigharvest update

sigharvest discover finds public repositories you do not have yet.

Health

synced
the last sync worked, less than 30 days ago
stale
no sync for more than 30 days
skipped
the last sync did not finish (the repository moved, went private or timed out); its rules from the last good sync are kept and the next update tries again
